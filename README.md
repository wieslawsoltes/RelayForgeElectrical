# RelayForge Electrical

Modular electrical CAD built with plain HTML, CSS, JavaScript and WebGPU, with a Canvas fallback. This repository contains the RelayForge Electrical 0.2.0 source, seven standalone libraries, tests, documentation, a Node/SQLite server and a static browser demo.

The server-backed edition provides revisioned SQL persistence and collaboration. The GitHub Pages edition stores projects locally in the browser; it does not provide remote accounts, SQL hosting or cross-device collaboration.

Original code and symbol artwork, licensed under MIT. This is not complete EPLAN Electric P8 parity, certified electrical engineering software, or a manufacturing-qualified system.
