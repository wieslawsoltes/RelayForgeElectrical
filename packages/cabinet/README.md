# @relayforge/cabinet — 0.2.0

Millimetre component geometry, collision checks, 3D grid routing and fabrication estimates. /renderer provides Canvas/WebGPU visualization. Not manufacturing-qualified.

MIT-licensed original source. No application runtime is required. The package uses native ES modules; install sibling @relayforge/core where declared. Browser-facing classes require modern DOM APIs.

See the repository docs/API.md for examples and docs/COMPATIBILITY.md for supported semantics and qualification boundaries. Package exports are listed in package.json. `npm pack` creates the standalone package archive.
