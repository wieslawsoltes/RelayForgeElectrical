# Feature and compatibility matrix — 0.2.0

RelayForge is original electrical CAD software. This release extends the earlier implementation substantially; it does not establish complete EPLAN Electric P8 compatibility or certified engineering fitness.

| Requested area | Implemented in this release | Remaining qualification or scope boundary |
|---|---|---|
| Native project/macro formats | Windows companion for documented EPLAN project exchange, backup/restore, macro generation and PLC actions; argument validation and dry-run tests | Requires an installed licensed EPLAN runtime. No proprietary binary decoder, native format renderer, EDZ importer or direct native-to-RelayForge project mapping. Actual EPLAN execution is untested. |
| Electrical-property semantics | 51 typed properties; local/main-function/part/default resolution; function-specific noninheritance; main-function diagnostics; terminal physical positions, levels and jumpers; feedthrough state; project potential/interruption networks | Not the complete EPLAN property/function-definition catalog, all representation rules, target tracking, cable assembly semantics or energized circuit simulation. |
| Symbols | 80 original editable vector definitions covering switching, protection, relays, motors/drives, terminals, PLC modules, sensors and electronics; registration API and catalog export | Not a comprehensive IEC/NFPA standard library, licensed EPLAN library or manufacturer data portal. Symbol likeness and pin meaning require review for the intended convention. |
| PLC interchange | PLCopen 2.01 POU declarations; Logix TAG/ALIAS CSV and scoped L5X scalar tags; AutomationML CAEX 2.15 APC tag interfaces; source preservation; namespace-safe bounded parser | PLCopen generated samples validated against official XSD. No PLC logic compiler, complete hardware topology, safety signatures, arrays/UDTs or lossless arbitrary vendor project roundtrip. |

## Interchange profiles

PLCopen maps each tag scope to a named program POU. A scope called `Controller` is a POU name here, not a claim of vendor controller-global semantics. Configuration/resource globals are rejected until an explicit mapping is selected. Supported types are BOOL, BYTE, WORD, DWORD, INT, DINT, REAL, LREAL and STRING.

Logix adapters support BOOL, INT, DINT and REAL scalar base tags, plus aliases. Controller and program scopes are retained. Unsupported IEC bit strings, LREAL, STRING structures, arrays and user types are rejected rather than silently converted. Initial values are not preserved in the mapped model; original import source remains available in the project. L5X exports initialize base scalar data to zero and are intended for reviewed tag exchange.

AutomationML maps APC tag interfaces. A RelayForge `Scope` attribute retains grouping; target tools may require their own tag-table/device structure and profile versions. The generated subset is not a complete AR APC hardware project.

All artwork and source are original. EPLAN is named only as a requested interoperability target. No EPLAN assets, licensed symbol databases, standard text, PLCopen XSD or AutomationML reference libraries are redistributed in this repository.
